Modelo Regresión con un Perceptrón Simple¶

El perceptrón original fue diseñado para clasificación, pero podemos adaptarlo para regresión usando una función de activación lineal en la salida.¶

Si bien el perceptrón original fue concebido por Frank Rosenblatt específicamente para problemas de clasificación binaria mediante una función de activación escalón que producía salidas discretas $( 0 o 1)$, su estructura fundamental puede reconceptualizarse para problemas de regresión mediante una modificación crucial: la sustitución de la función de activación no lineal por una función de identidad lineal en la capa de salida. Esta adaptación transforma el modelo de un clasificador binario a un predictor continuo, donde la combinación lineal de entradas y pesos $$\hat{y}= \mathbf{w}^T \mathbf{x}+b$$ se preserva directamente como salida, permitiendo así predecir valores en el dominio real. Matemáticamente, esta versión para regresión equivale a una regresión lineal simple cuando se tiene una sola característica, pero conserva la esencia del aprendizaje iterativo mediante descenso de gradiente donde los parámetros $$\mathbf{w} \, \, b$$ se actualizan minimizando el error cuadrático medio en lugar de la función de pérdida perceptrón original. Sin embargo, esta simplicidad constituye también su principal limitación, ya que al carecer de funciones de activación no lineales en capas ocultas, el modelo solo puede capturar relaciones lineales entre variables, siendo incapaz de modelar patrones complejos o no lineales presentes en muchos problemas del mundo real, lo que explica por qué fue superado por arquitecturas más sofisticadas como el MLP (Perceptrón Multicapa) que reintroducen no linealidades mediante funciones como ReLU o tanh en capas intermedias.¶

def generar_datos_lineales(n_muestras=100, ruido=2.0):
    """
    Genera datos con relación lineal: y = 2*x + 3 + ruido
    """
    np.random.seed(42)
    
    # Generar feature
    x = np.random.uniform(-10, 10, n_muestras)
    
    # Relación lineal con ruido
    y = 2 * x + 3 + np.random.normal(0, ruido, n_muestras)
    
    return x.reshape(-1, 1), y

Implementación del Perceptrón para Regresión¶

Las matemática detras del Perceptrón son:¶

$$ \hat{y} = w \cdot x + b $$

Donde:¶

- (w): peso¶

- (b): bias (sesgo)¶

- (x): entrada¶

- (\hat{y}): predicción¶

class PerceptronRegresion:
    """
    Implementación de un perceptrón simple para regresión
    """
    
    def __init__(self, learning_rate=0.01, n_epochs=100):
        self.learning_rate = learning_rate
        self.n_epochs = n_epochs
        self.w = None  # peso
        self.b = None  # bias
        self.loss_history = []
        
    def initialize_parameters(self, n_features):
        """Inicializa pesos y bias aleatoriamente"""
        self.w = np.random.normal(0, 0.1, n_features)
        self.b = np.random.normal(0, 0.1)
        
    def predict(self, X):
        """Predicción: y_hat = w*x + b"""
        return np.dot(X, self.w) + self.b
    
    def compute_loss(self, y_true, y_pred):
        """Calcula el error cuadrático medio"""
        return np.mean((y_true - y_pred) ** 2)
    
    def compute_gradients(self, X, y_true, y_pred):
        """Calcula gradientes para w y b"""
        n_samples = len(y_true)
        
        # Gradientes de la función de pérdida MSE
        dw = (-2/n_samples) * np.dot(X.T, (y_true - y_pred))
        db = (-2/n_samples) * np.sum(y_true - y_pred)
        
        return dw, db
    
    def fit(self, X, y, verbose=True):
        """
        Entrena el perceptrón usando descenso de gradiente
        """
        n_samples, n_features = X.shape
        
        # Inicializar parámetros
        self.initialize_parameters(n_features)
        
        # Historial para visualización
        self.loss_history = []
        self.w_history = [self.w.copy()]
        self.b_history = [self.b]
        
        print("Iniciando entrenamiento del perceptrón...")
        print(f"Parámetros iniciales: w = {self.w[0]:.4f}, b = {self.b:.4f}")
        
        for epoch in range(self.n_epochs):
            # Predicción forward
            y_pred = self.predict(X)
            
            # Cálculo de pérdida
            loss = self.compute_loss(y, y_pred)
            self.loss_history.append(loss)
            
            # Cálculo de gradientes
            dw, db = self.compute_gradients(X, y, y_pred)
            
            # Actualización de parámetros
            self.w -= self.learning_rate * dw
            self.b -= self.learning_rate * db
            
            # Guardar historial
            self.w_history.append(self.w.copy())
            self.b_history.append(self.b)
            
            # Mostrar progreso cada 10 épocas
            if verbose and (epoch % 20 == 0 or epoch == self.n_epochs - 1):
                print(f"Época {epoch:3d}: Loss = {loss:.4f}, w = {self.w[0]:.4f}, b = {self.b:.4f}")
        
        print(f"Entrenamiento completado. Parámetros finales: w = {self.w[0]:.4f}, b = {self.b:.4f}")
        
    def get_parameters(self):
        """Retorna los parámetros del modelo"""
        return {'w': self.w, 'b': self.b}

# Función auxiliar para hacer predicciones con nuevo datos
def predecir_con_perceptron(modelo, nuevos_datos):
    """
    Realiza predicciones con nuevos datos usando el perceptrón entrenado
    
    Parameters:
    modelo: PerceptronRegresion entrenado
    nuevos_datos: array-like, datos nuevos para predecir
    
    Returns:
    predicciones: array con las predicciones
    """
    # Convertir a numpy array y asegurar la forma correcta
    nuevos_datos = np.array(nuevos_datos)
    if len(nuevos_datos.shape) == 1:
        nuevos_datos = nuevos_datos.reshape(-1, 1)
    
    # Hacer predicciones
    predicciones = modelo.predict(nuevos_datos)
    return predicciones

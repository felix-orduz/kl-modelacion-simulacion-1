Practicando con ecuaciones en diferencias¶

Las ecuaciones en diferencias son relaciones que expresan el valor de una variable en términos de sus valores anteriores. Son el análogo discreto de las ecuaciones diferenciales y se utilizan para modelar sistemas que evolucionan en tiempo discreto. Una ecuación en diferencias de orden $k$ tiene la forma:¶

$$x_{n+k} = f(n, x_n, x_{n+1}, \dots, x_{n+k-1})$$

Para ecuaciones de primer orden:¶

$$x_{n+1} = f(n, x_n)$$

Para ecuaciones autónomas (donde $f$ no depende explícitamente de $n$):¶

$$x_{n+1} = f(x_n)$$

las Ecuaciones en Diferencias son clasificadas por:¶

1. Por Linealidad¶

Lineales: $$x_{n+1} = a_n x_n + b_n$$

No lineales: $$x_{n+1} = f(x_n) \quad \text{donde } f \text{ es no lineal}$$

2. Por Orden¶

  • Primer orden: $x_{n+1} = f(x_n)$
  • Segundo orden: $x_{n+2} = f(x_n, x_{n+1})$
  • Orden superior: $x_{n+k} = f(x_n, x_{n+1}, \dots, x_{n+k-1})$

3. Por Autonomía¶

Autónomas: No dependen explícitamente de $n$ $$x_{n+1} = f(x_n)$$

No autónomas: Dependen explícitamente de $n$ $$x_{n+1} = f(n, x_n)$$

La solución de una ecuación en diferencias es una secuencia $\{x_n\}$ que satisface la ecuación para todo $n$ con una condición Inicial¶

tal que para una ecuación de orden $k$, se necesitan $k$ valores iniciales:¶

$$x_0, x_1, \dots, x_{k-1}$$

Ejemplo 1:¶

Modelo de Ahorro con Interés Compuesto¶

Un individuo deposita $1000$ en una cuenta de ahorros que paga un interés mensual del $1%$. Cada mes adicional, deposita $200$ más. Este modelo corresponde a muchos sistemas financieros como:¶

- Planes de ahorro programado¶

- Fondos de pensiones¶

- Amortización de deudas¶

- Inversiones con aportes periódicos¶

El modelo se describe mediante mediante una ecuación en diferencias Lineal¶

$$A_{n+1} = (1 + r)A_n + D$$

donde:¶

  • $A_n$: Saldo en el mes $n$
  • $r$: Tasa de interés mensual (1% = 0.01)
  • $D$: Depósito mensual adicional ($200)
  • $A_0$: Depósito inicial ($1000)

y los parámetros del modelo están dados por:¶

  • $r = 0.01$ (1% mensual)
  • $D = 200$
  • $A_0 = 1000$

La solución analítica para una ecuación en diferencias lineal de primer orden:¶

$$A_{n+1} = aA_n + b$$

esta dada por:¶

$$A_n = a^n A_0 + b \frac{1 - a^n}{1 - a} \quad \text{para } a \neq 1$$

Para nuestro caso sustituyendo $a = (1 + r)$ y $b = D$ obtenemos:¶

$$A_n = (1 + r)^n A_0 + D \frac{1 - (1 + r)^n}{1 - (1 + r)}$$

simplificando¶

$$A_n = (1 + r)^n A_0 + D \frac{(1 + r)^n - 1}{r}$$

Asi para nuestros parámetros obtenemos:¶

$$A_n = (1.01)^n \times 1000 + 200 \times \frac{(1.01)^n - 1}{0.01}$$

import numpy as np
import matplotlib.pyplot as plt
import pandas as pd

# Parámetros del modelo
r = 0.01    # Tasa de interés mensual 1%
D = 200     # Depósito mensual
A0 = 1000   # Depósito inicial
n_meses = 24  # 2 años de análisis

# Función de la solución analítica
def saldo_analitico(n, r, D, A0):
    return (1 + r)**n * A0 + D * ((1 + r)**n - 1) / r

# Simulación iterativa
def simulacion_ahorro(A0, r, D, n_meses):
    A = [A0]
    for n in range(n_meses):
        A_next = (1 + r) * A[-1] + D
        A.append(A_next)
    return np.array(A)

# Calculamos ambas soluciones
meses = np.arange(0, n_meses + 1)
saldo_analitico_valores = saldo_analitico(meses, r, D, A0)
saldo_iterativo = simulacion_ahorro(A0, r, D, n_meses)

# Crear tabla de resultados
print("Evolución del saldo (primeros 12 meses)")
print("=" * 40)
print(f"{'Mes':<6} {'Saldo Analítico':<15} {'Saldo Iterativo':<15}")
print("-" * 40)
for i in range(13):
    print(f"{i:<6} ${saldo_analitico_valores[i]:<14.2f} ${saldo_iterativo[i]:<14.2f}")

# Gráfico de la evolución del saldo
plt.figure(figsize=(12, 6))
plt.plot(meses, saldo_analitico_valores, 'b-', linewidth=2, label='Solución Analítica')
plt.plot(meses, saldo_iterativo, 'ro', markersize=4, label='Solución Iterativa')
plt.xlabel('Meses')

Punto de Equilibrio¶

El punto de equilibrio $A^*$ satisface:¶

$$A^* = (1 + r)A^* + D$$

Resolviendo:¶

$$A^* - (1 + r)A^* = D$$ $$-rA^* = D$$ $$A^* = -\frac{D}{r}$$

Sin embargo, este equilibrio es inestable ya que $|1 + r| > 1$.¶

Ejemplo 2:¶

Modelo de crecimiento poblacional¶

Consideremos una población de bacterias que se reproduce cada hora. Cada bacteria se divide en dos nuevas bacterias al final de cada período. Sin embargo, debido a limitaciones de espacio y recursos, existe una capacidad máxima de carga $K$ en el ambiente.¶

El modelo se describe mediante la ecuación logística en diferencias:¶

$$ P_{n+1} = P_n + rP_n\left(1 - \frac{P_n}{K}\right) $$

donde:

  • $P_n$: Población en el tiempo $n$
  • $r$: Tasa de crecimiento intrínseca
  • $K$: Capacidad de carga del ambiente

Para nuestro ejemplo, consideremos:

\begin{align*} r &= 0.8 \quad \text{(tasa de crecimiento)} \\ K &= 1000 \quad \text{(capacidad máxima)} \\ P_0 &= 100 \quad \text{(población inicial)} \end{align*}

La solución se obtiene iterando la ecuación:

\begin{align*} P_1 &= P_0 + rP_0\left(1 - \frac{P_0}{K}\right) = 100 + 0.8 \times 100 \times \left(1 - \frac{100}{1000}\right) = 172 \\ P_2 &= P_1 + rP_1\left(1 - \frac{P_1}{K}\right) = 172 + 0.8 \times 172 \times \left(1 - \frac{172}{1000}\right) \approx 286 \\ P_3 &= 286 + 0.8 \times 286 \times \left(1 - \frac{286}{1000}\right) \approx 449 \\ &\vdots \end{align*}

Veamos la evolución de la población para las primeras 10 iteraciones

Para la ecuación logística en diferencias, los puntos de equilibrio se encuentran resolviendo:

$$ P^* = P^* + rP^*\left(1 - \frac{P^*}{K}\right) $$

Lo que implica:

$$ rP^*\left(1 - \frac{P^*}{K}\right) = 0 $$

Los puntos de equilibrio son: \begin{align*} P^* &= 0 \quad \text{(equilibrio trivial)} \\ P^* &= K \quad \text{(capacidad de carga)} \end{align*}

La estabilidad del punto $P^* = K$ se analiza mediante la derivada:

$$ f(P) = P + rP\left(1 - \frac{P}{K}\right) $$$$ f'(P) = 1 + r - \frac{2rP}{K} $$

Evaluando en $P^* = K$:

$$ f'(K) = 1 + r - 2r = 1 - r $$

El equilibrio es estable si $|1 - r| < 1$, es decir, si $0 < r < 2$.

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import fsolve

# Configuración de estilo para los gráficos
plt.style.use('default')
plt.rcParams['figure.figsize'] = (12, 8)
plt.rcParams['font.size'] = 12

# Parámetros del modelo
r = 0.8
K = 1000
P0 = 100
n_steps = 20

# Función del modelo logístico
def logistic_model(P, r, K):
    """Ecuación en diferencias del modelo logístico"""
    return P + r * P * (1 - P / K)

# Simulación de la población
def simulate_population(P0, r, K, n_steps):
    """Simula la evolución de la población"""
    P = [P0]
    for n in range(n_steps):
        P_next = logistic_model(P[-1], r, K)
        P.append(P_next)
    return np.array(P)

# Encontrar puntos de equilibrio
def find_equilibrium(r, K):
    """Encuentra los puntos de equilibrio"""
    # Puntos de equilibrio: P* = 0 y P* = K
    equilibria = [0, K]
    
    # Verificar estabilidad
    def f_prime(P):
        return 1 + r - (2 * r * P) / K
    
    stability = {}
    for eq in equilibria:
        derivative = f_prime(eq)
        if abs(derivative) < 1:
            stability[eq] = "Estable"
        else:
            stability[eq] = "Inestable"
    
    return equilibria, stability

# Simular la población
time_steps = np.arange(0, n_steps + 1)
population = simulate_population(P0, r, K, n_steps)

# Encontrar puntos de equilibrio
equilibria, stability = find_equilibrium(r, K)
